# Графический интерфейс AccessHub (UI/UX)

Документ описывает графический интерфейс бота с точки зрения пользователя и инструкции по тестированию.

---

## Обзор

AccessHub теперь имеет **графический интерфейс** с кнопками и меню, что делает работу с ботом более удобной и интуитивной. Интерфейс адаптируется в зависимости от роли пользователя (оператор или администратор).

---

## Типы клавиатур

### 1. Reply-клавиатура (нижняя клавиатура)

Появляется внизу экрана Telegram и содержит быстрые команды. Видна постоянно, пока не скрыта.

**Для оператора:**
```
[/menu]  [/history]
[/help]
```

**Для администратора:**
```
[/menu]  [/history]
[/help]
[/add]  [/import]
[/stats]  [/log 1]
```

### 2. Inline-клавиатура (кнопки в сообщении)

Кнопки внутри сообщения, которые можно нажимать. Сообщение обновляется при нажатии.

---

## Главное меню (`/menu`)

### Для оператора

Отправьте `/menu` в боте.

**Что видно:**
- Сообщение: "AccessHub — меню (Оператор)\nВыбери действие:"
- Inline-кнопки:
  - `[Получить аккаунт]` `[Моя история]`
  - `[Помощь]`
  - `[Обновить]`

### Для администратора

Отправьте `/menu` в боте.

**Что видно:**
- Сообщение: "AccessHub — меню (Админ)\nВыбери действие:"
- Inline-кнопки:
  - `[Получить аккаунт]` `[Моя история]`
  - `[Помощь]`
  - `[➕ Добавить]` `[📥 Импорт]`
  - `[📊 Статистика]` `[🧾 Логи]`
  - `[🔎 Поиск]` `[📤 Экспорт]`
  - `[👥 Пользователи]` `[Обновить]`

## Функции оператора

### 1. Получить аккаунт

**Способ 1: через меню**
1. Нажмите `/menu`
2. Нажмите кнопку `[Получить аккаунт]`
3. Появится инструкция по формату запроса

**Способ 2: напрямую (как раньше)**
Отправьте боту:
```
2446303
Minecraft (Xbox X)
```

**Ожидаемый результат:**
```
Заказ: 2446303
Игра: Minecraft
Платформа: Xbox X

#1
Login: test_minecraft_xbox_1
Password: test_pass_123
```

**Особенности:**
- После выдачи появляется Reply-клавиатура для быстрого доступа
- Можно запросить несколько аккаунтов: `Minecraft (Xbox X) x2`

### 2. Моя история

**Способ 1: через меню**
1. Нажмите `/menu`
2. Нажмите кнопку `[Моя история]`
3. Сообщение обновится и покажет последние 10 выдач

**Способ 2: через команду**
Отправьте `/history`

**Ожидаемый результат:**
```
Последние выдачи (10):

2025-12-15 14:30:25 | order: 2446303 | Minecraft (Xbox X) | account: 1
2025-12-15 14:25:10 | order: 2446302 | Call of Duty (PS5) | account: 3
...
```

**Особенности:**
- Показываются только ваши выдачи
- Отсортированы по дате (новые сверху)
- Кнопка `[Назад]` возвращает в главное меню

### 3. Помощь

**Способ 1: через меню**
1. Нажмите `/menu`
2. Нажмите кнопку `[Помощь]`
3. Сообщение обновится со справкой

**Способ 2: через команду**
Отправьте `/help` или `/start`

**Ожидаемый результат:**
```
AccessHub — команды:

Оператор:
/menu — меню
/history — последние выдачи

Выдача:
2 строки: order_id + 'Game (Platform)'
Qty (тест): 'x2' в конце второй строки

Админ:
/add — мастер добавления
/abort — отмена мастера
/import — импорт текстом/файлом
/log <id> — логи по аккаунту
/stats — статистика
```

## Функции администратора

### 1. ➕ Добавить аккаунт

**Способ 1: через меню**
1. Нажмите `/menu`
2. Нажмите кнопку `[➕ Добавить]`
3. Запустится пошаговый мастер добавления аккаунта

**Способ 2: через команду**
Отправьте `/add`

**Ожидаемый результат:**
Бот начнёт задавать вопросы по порядку:
1. Платформа
2. Игра
3. Логин игрового аккаунта
4. Пароль игрового аккаунта
5. Логин почты (можно `skip`)
6. Пароль почты (можно `skip`)
7. Почты для кодов (можно `skip`)
8. Доп. данные платформы (можно `skip`)

После завершения:
```
Готово. Аккаунт добавлен.
ID: 15
Minecraft (Xbox X)
Login: new_account_login
```

**Особенности:**
- Можно отменить мастер командой `/abort`
- Опциональные поля можно пропустить через `skip`
- После завершения появляется Reply-клавиатура

### 2. 📥 Импорт

**Способ 1: через меню**
1. Нажмите `/menu`
2. Нажмите кнопку `[📥 Импорт]`
3. Появится инструкция по формату импорта

**Способ 2: через команду**
Отправьте `/import` или `/import` с данными

**Ожидаемый результат:**
При нажатии кнопки в меню:
```
Импорт:
— отправь /import + строки
или
— пришли TXT-файл документом.

Формат:
Platform | Game | login | pass | email | emailpass | backupEmails
```

**Импорт текстом:**
```
/import
Xbox X | Forza Horizon 5 | forza_user_1 | forza_pass_1 | forza@mail.com | mailpass1 | backup@mail.com
Xbox X | Forza Horizon 5 | forza_user_2 | forza_pass_2 | - | - | -
```

**Ожидаемый результат:**
```
Добавлено: 2
Пропущено: 0
Ошибок: 0
```

**Импорт из файла:**
1. Создайте TXT-файл с данными
2. Отправьте файл боту как документ (не фото!)
3. Бот автоматически обработает файл

**Особенности:**
- Дубликаты автоматически пропускаются
- Ошибки формата обрабатываются
- Комментарии (строки с `#`) игнорируются

### 3. 📊 Статистика

**Способ 1: через меню**
1. Нажмите `/menu`
2. Нажмите кнопку `[📊 Статистика]`
3. Сообщение обновится со статистикой

**Способ 2: через команду**
Отправьте `/stats`

**Ожидаемый результат:**
```
Статистика AccessHub:
Всего аккаунтов: 15
Активных: 14
Доступны сейчас: 10
На паузе (ожидание): 4
```

**Особенности:**
- Обновляется в реальном времени
- Показывает актуальное состояние базы
- Кнопка `[Назад]` возвращает в меню

### 4. 🧾 Логи

**Способ 1: через меню**
1. Нажмите `/menu`
2. Нажмите кнопку `[🧾 Логи]`
3. Появится инструкция по использованию

**Способ 2: через команду**

**Ожидаемый результат:**
При нажатии кнопки:
```

Пример: /log 12
```

При использовании команды:
```

2025-12-15 14:30:25 | order: 2446303 | operator: 123456789
2025-12-15 13:15:10 | order: 2446302 | operator: 123456789
...
```

**Особенности:**

- Включает дату, номер заказа и ID оператора
- Кнопка `[Назад]` возвращает в меню

## Навигация

### Кнопка "Назад"

В большинстве экранов есть кнопка `[Назад]`, которая возвращает в главное меню.

### Кнопка "Обновить"

В главном меню есть кнопка `[Обновить]`, которая обновляет текущий экран меню.

## Что тестировать

### ✅ 1. Главное меню

**Тест 1.1: Открытие меню**
1. Отправьте `/menu`
2. Должно появиться сообщение с inline-кнопками
3. Для оператора — 3 кнопки (Получить аккаунт, Моя история, Помощь)
4. Для админа — дополнительные кнопки (Добавить, Импорт, Статистика, Логи, Поиск, Экспорт, Пользователи)

**Тест 1.2: Навигация по кнопкам**
1. Откройте меню
2. Нажмите любую кнопку
3. Сообщение должно обновиться (не создаваться новое)
4. Должна появиться кнопка `[Назад]` (кроме главного меню)

**Тест 1.3: Кнопка "Назад"**
1. Откройте меню
2. Нажмите любую кнопку (например, "Моя история")
3. Нажмите `[Назад]`
4. Должно вернуться главное меню

**Тест 1.4: Кнопка "Обновить"**
1. Откройте меню
2. Нажмите `[Обновить]`
3. Меню должно обновиться (сообщение остаётся тем же)

### ✅ 2. Reply-клавиатура

**Тест 2.1: Появление клавиатуры**
1. Отправьте `/help` или `/start`

3. Для оператора — 3 строки кнопок
4. Для админа — дополнительные строки

**Тест 2.2: Использование кнопок**
1. Нажмите любую кнопку на Reply-клавиатуре (например, `/menu`)
2. Команда должна отправиться автоматически
3. Бот должен обработать команду

**Тест 2.3: Клавиатура после выдачи**
1. Сделайте выдачу аккаунта (2 строки)
2. После получения ответа должна появиться Reply-клавиатура
3. Клавиатура должна соответствовать вашей роли

### ✅ 3. Функции оператора

### ✅ 5. Права доступа

**Тест 5.1: Оператор не видит админские кнопки**
1. Войдите как оператор
2. Откройте `/menu`
3. Не должно быть админских кнопок (Добавить, Импорт, Статистика и т.д.)

**Тест 5.2: Оператор не может использовать админские команды**
1. Войдите как оператор
2. Попробуйте отправить `/add` или `/stats`
3. Должно появиться сообщение "Нет прав."

**Тест 5.3: Админ видит все кнопки**
1. Войдите как администратор
2. Откройте `/menu`
3. Должны быть видны все кнопки (операторские + админские)

### ✅ 6. Обратная совместимость

**Тест 6.1: Текстовые команды работают**
1. Отправьте команды напрямую: `/add`, `/import`, `/history`, `/stats`
2. Все команды должны работать как раньше

**Тест 6.2: Выдача аккаунта текстом**
1. Отправьте запрос в старом формате (2 строки)
2. Должна работать выдача аккаунта
3. После ответа должна появиться Reply-клавиатура

**Тест 6.3: Мастер добавления**
1. Отправьте `/add`
2. Мастер должен запуститься
3. Можно использовать `/abort` для отмены

### ✅ 7. Обработка ошибок

**Тест 7.1: Неизвестный callback**
1. Откройте меню
2. Попробуйте отправить несуществующий callback (через API, если возможно)
3. Должно обработаться корректно

**Тест 7.2: Неверный формат запроса**
1. Отправьте неверный формат (например, одну строку)
2. Должно появиться сообщение с подсказкой
3. Должна появиться Reply-клавиатура

**Тест 7.3: Нет доступа**
1. Войдите как пользователь, не добавленный в систему
2. Попробуйте использовать бота
3. Должно появиться сообщение "Нет доступа. Обратитесь к администратору."

## Частые вопросы

### Как скрыть Reply-клавиатуру?

Reply-клавиатура скрывается автоматически при использовании inline-кнопок или при отправке команды, которая не требует клавиатуры. В текущей реализации клавиатура остаётся видимой для удобства.

### Можно ли использовать старые команды?

Да, все текстовые команды продолжают работать. Интерфейс дополняет, а не заменяет их.

### Почему некоторые кнопки показывают "скоро"?

Это заглушки для будущих функций (Поиск, Экспорт, Пользователи). Они будут реализованы позже.

### Как работает кнопка "Обновить"?

Кнопка `[Обновить]` в главном меню обновляет текущее сообщение меню. Это полезно, если нужно обновить состояние (например, после изменения прав доступа).
